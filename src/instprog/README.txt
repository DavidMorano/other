INSTPROG

This progam installs a file to one or more target directories with
optionally specified names.

Synopsis:
$ installprog [-d <dir(s)>] <file> [<name(s)>]

Arguments:
-d <dir(s)>	optionally specified target directories
<file>		file, the program, to install
<name(s)>	optonal names to install the program as
